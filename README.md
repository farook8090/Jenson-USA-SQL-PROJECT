# 🛒 Jenson USA – SQL Analysis Project

This project focuses on deriving business insights from the Jenson USA dataset using SQL queries. As a data analyst at Jenson’s, the goal was to analyze customer behavior, staff performance, inventory management, and store operations to support data-driven decision-making.

![Main page dashboard](https://github.com/farook8090/Jenson-USA-SQL-PROJECT/blob/4dd7e31b71f17c12512d708cabfb0e0e7405a959/1.png)

# 📊 Project Overview

The dataset contains information on customers, staff, products, stores, and orders. Using SQL, I explored key business questions such as:

Sales performance across stores and products

Customer spending patterns and order behaviors

Staff sales performance and productivity

Inventory insights, including unsold products and pricing trends

# 🛠️ Key SQL Queries & Insights

Calculated total products sold per store to measure sales distribution.

Computed cumulative quantities sold for each product over time.

Identified the highest revenue-generating product in each category.

Tracked the top-spending customer across all orders.

Retrieved the highest-priced product per category.

Analyzed order counts per customer per store.

Detected staff members with no sales activity.

Listed the top 3 most sold products by quantity.

Derived the median price value from the product list.

Used EXISTS to identify products never ordered.

Compared staff sales to find those exceeding average performance.

Identified customers who purchased from every category.

# 📑 Deliverables

SQL Scripts – Queries to answer all business questions.

PowerPoint Presentation – Structured report of problem statements, queries, and insights.
